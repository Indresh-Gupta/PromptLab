# PromptVerse – AI Chat Assistant with Google Gemini API

PromptVerse is a full-stack conversational AI web application that allows users to chat with Google's Gemini API to get intelligent answers to any prompt. Inspired by platforms like ChatGPT, it supports secure authentication, persistent chat history, and a clean, user-friendly interface.

---

##  Tech Stack

- **Frontend:** React.js   
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT (JSON Web Tokens)  
- **AI Integration:** Google Gemini API (via REST)

---

##  Features

-  **JWT Authentication**
  - Sign up and log in securely with JWT.
  - Token-based access for all chat endpoints.

-  **AI Chat Interface**
  - Communicate with Gemini AI using user prompts.
  - Real-time question-answer format.

-  **Chat History Management**
  - View previous conversations anytime.
  - Delete individual chats or entire conversation history.
  - Start new chats or continue previous ones.

-  **Modern UI**
  - UI designed to mirror ChatGPT-style layout.
  - Responsive and clean interface for both desktop and mobile.
